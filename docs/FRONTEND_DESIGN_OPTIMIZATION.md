## 🎨 设计系统统一

### 颜色方案
- **主色**: 蓝色（#3b82f6）
- **辅助色**: 紫色（渐变）
- **成功**: 绿色（#22c55e）
- **错误**: 红色（#ef4444）
- **警告**: 橙色（#f59e0b）
- **中性**: 灰色梯度

### 动画时长
- **快速**: 150ms（按钮、开关）
- **标准**: 250ms（卡片、菜单）
- **慢速**: 350ms（面板、模态框）

### 间距系统
- **xs**: 0.25rem (4px)
- **sm**: 0.5rem (8px)
- **md**: 1rem (16px)
- **lg**: 1.5rem (24px)
- **xl**: 2rem (32px)
- **2xl**: 3rem (48px)

### 圆角
- **sm**: 0.25rem
- **md**: 0.5rem
- **lg**: 0.75rem
- **xl**: 1rem
- **full**: 9999px

### 阴影层级
- **sm**: 悬停提示
- **md**: 卡片默认
- **lg**: 卡片悬停
- **xl**: 模态框

## 🚀 核心特性

### Glass Morphism（毛玻璃）
```css
.glass {
  background: rgba(255, 255, 255, 0.8);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.3);
}
```

### 渐变背景
```css
.gradient-primary {
  background: linear-gradient(135deg, #2563eb 0%, #1e40af 100%);
}
```

### 卡片悬停
```css
.card-hover:hover {
  transform: translateY(-2px);
  box-shadow: var(--shadow-lg);
}
```

### 骨架屏
```css
.skeleton {
  background: linear-gradient(90deg, #f3f4f6 25%, #e5e7eb 50%, #f3f4f6 75%);
  animation: shimmer 1.5s infinite;
}
```

## 💡 使用建议

### 1. 保持一致性
- 使用 CSS 变量而非硬编码
- 遵循既定的间距系统
- 使用预定义的动画类

### 2. 性能优先
- 优先使用 CSS 变量
- 避免不必要的动画
- 使用骨架屏代替空白

### 3. 可访问性
- 保持足够的颜色对比度
- 使用语义化的 HTML
- 提供清晰的焦点状态
